# BigData

For the json files to create them you go to the company website and you take the name of all the items on the menu and add it to a text file along with the price. From there Then we converted the text files into json files to be able to use them as our database.

For it to work you need to install Streamlit. Once it is installed then in order for us to run the program we run the command: streamlit run frontend/app.py
